Diabetes Prediction Pipeline Architecture

Scikit-learn • Statistical Imputation • Feature Standardization

1. Problem Formulation & Dataset

The system predicts whether a patient has diabetes based on diagnostic measurements (Glucose, Blood Pressure, Skin Thickness, Insulin, BMI, Diabetes Pedigree Function, and Age).

2. Handling Missing Biological Values

In biological datasets, zero values in fields like Blood Pressure, Glucose, or Insulin represent sensor absence or unrecorded data rather than true physiological zeros. Subham implemented statistical median imputation conditioned on class labels to prevent data bias.

3. Z-Score Feature Standardization

Because features vary across differing measurement scales (Insulin up to 800, Glucose up to 200, BMI around 30), features were standardized using z = (x - μ) / σ, ensuring gradient descent converges efficiently in Logistic Regression.

4. Model Performance Metrics
